# 桌面执行池启用判据与 Runbook（M2）

> M0/M1 不部署。只有满足主文档表 6-15 任一判据才建池。

## 判据
1. 目标动作无官方接口且无后台导出（活动报名页、商品编辑页、类目属性勾选）。
2. 必须操作 Windows 原生客户端或无 DOM 的桌面程序（ERP 客户端、旧版商家工具、WPS/Excel COM）。
3. 后台报表必须人工点「导出」且接口不覆盖所需字段。
4. 需要保留登录态、滑块、2FA 的真实浏览器环境。

## 启用前检查
- [ ] 「接口 / 后台导出 / 必须点页面」三列逐平台清单已产出，且本场景在「必须点页面」列。
- [ ] Worker API 契约未变；`POST /write` 强校验（task_id + 批准态 + 短时效）已实现并测过。
- [ ] 机器人按「平台 + 店铺」分组、串行执行、固定分辨率与 DPI、会话解锁、禁用屏保与自动锁屏。
- [ ] 专用子账号 + 凭据库引用（不落明文）+ 到期提醒 + 月度权限复核。
- [ ] 触发滑块/验证码/2FA 即降级或转人工，禁止自动绕过。
- [ ] 失败保留现场截图，进死信并生成 TODO-EXCEPTION。

## 回滚
- 桌面池异常时把 `mod_worker_desktop` 置 DISABLED，调度自动回落到无桌面通道；只读场景不受影响。
